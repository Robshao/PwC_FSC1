# 提示詞範本

`<尖括號>` 是要替換的內容；用不到的句子直接刪掉。

## 1. 鏡頭圖片提示詞（keyframe）

```text
參考上傳的大頭照：保持完全相同的臉型、五官、膚色和髮型，不要美化、不要改變年齡。

寫實攝影風格的電影劇照，16:9。<時間>，<場景>。大頭照中的同一人穿著<服裝>，<動作的第一個瞬間>，<表情>。<背景細節>。

<景別與角度>。<主光源與方向>，<輔助光與色調>。淺景深，自然膚質。

畫面中只有<人數>。不要出現文字、商標、浮水印。
```

沒有大頭照（原創角色）時，把第一段換成具體的人物描述：年齡、外型特徵、髮型、服裝，並在每個鏡頭用完全相同的描述。

## 2. 圖生影片提示詞（i2v）

```text
@Image 1 定義開場畫面的人物、構圖和場景。保持人物的臉、服裝、人數和空間關係不變。

從圖片自然開始。<一個主要動作，包含開始、變化和結束>。結束畫面：<看得見的最終狀態>。

鏡頭：<一個運鏡，包含起點、方向和終點>。
光線：維持<圖片中的光線設定>。
聲音：<環境音>，<動作音效>。沒有對白，沒有背景音樂。

不要改變人物的臉，不要加入字幕、文字、商標或其他人物。
```

## 3. 情緒寫法

把抽象情緒換成 2–4 個看得見的細節：

| 抽象 | 改寫成 |
|---|---|
| 很有決心 | 深吸一口氣、抬頭、嘴角帶著堅定的微笑 |
| 很開心 | 眼睛微彎、笑容放大、肩膀放鬆 |
| 很驕傲 | 退後半步看著成果、下巴微抬、安靜的微笑 |
| 很專注 | 身體前傾、眉頭微皺、視線停在手上的東西 |

## 4. 常用運鏡

| 中文 | 英文 | 畫面效果 |
|---|---|---|
| 推進 | dolly in | 逐漸靠近主角，強調情緒 |
| 後拉 | dolly back | 逐漸拉遠，揭露整個場景 |
| 環繞 | arc | 繞著人物移動，增加動感 |
| 跟拍 | tracking | 跟著人物移動 |
| 固定鏡頭 | locked-off | 畫面不動，只有人物動 |
| 搖鏡 | pan | 鏡頭左右轉動 |

## 5. 常見問題與修正

| 問題 | 只改這一個地方 |
|---|---|
| 臉不像本人 | 加入大頭照當 `@Image 2`，只控制臉部 |
| 動作沒做完 | 縮短動作描述，只留一個動作與結束畫面 |
| 鏡頭亂跳 | 刪掉多餘的運鏡，只留一個 |
| 畫面出現亂碼文字 | 在排除項目加上「不要出現任何文字、招牌、螢幕內容」 |
| 多出其他人物 | 在開頭寫明「畫面中只有一個人」 |
