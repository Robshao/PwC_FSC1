# Seedance 提示詞寫法（進階）

> 整理自開源專案 OpenMontage 的 Seedance 2.0 提示詞指南（calesthio/OpenMontage，AGPLv3），再依我們在即夢實際生成的經驗改寫成繁體中文。原文沒有複製進來，只摘要做法。

## 一、提示詞的 8 個元素（需要哪個寫哪個）

| # | 元素 | 範例 |
|---|---|---|
| 1 | 景別 | 全景、中景、近景、特寫、空景 |
| 2 | 鏡頭運動 | 固定、緩慢推近、緩慢拉遠、上搖、手持輕晃 |
| 3 | 人物外觀（身分錨點） | 「灰白短髮、深灰西裝、深藍領帶的黃副總」 |
| 4 | 動作節拍 | 一句一個動作；不要超過 3 個同時進行的動作 |
| 5 | 場景 | 地點、時間、天氣 |
| 6 | 光線與色調 | 只選一種，例如「白天明亮的自然光」，不要混用衝突的光線 |
| 7 | 風格 | 寫實電影感、商業形象片 |
| 8 | 聲音 | 環境音、音效、台詞；配樂一律後製加，不要叫 Seedance 生成完整配樂 |

## 二、我們的固定規則（已驗證）

- 開頭固定寫「【重要：這是一支必須有聲音的影片】⋯」，否則容易生成無聲影片。
- 台詞放在 `{ }` 裡，並寫明說話者的年齡、性別、口音與語氣。
- 「除了這句台詞，不要有其他人說話」，避免其他人也開口。
- 結尾固定寫「不要改變人物的臉」與「不要出現任何文字、商標」。

## 三、多鏡頭寫法（一次生成多個鏡頭）

Seedance 2.0 可以在一次生成裡切好幾個鏡頭，鏡頭之間的人物、光線比分開生成更一致。即夢若有「多鏡頭」或可上傳多張參考圖的模式（例如全能參考），可以這樣寫：

```
鏡頭一（中景，緩慢推近，3 秒）：灰白短髮、深灰西裝、深藍領帶的黃副總站在大螢幕旁，手指著螢幕。
鏡頭二（特寫，固定，2 秒）：大螢幕正面，深藍色儀表板。
鏡頭三（近景，固定，2 秒）：短髮、細黑框眼鏡、白襯衫的怡君坐在桌邊，眉頭微皺看向螢幕。
```

重點：
- **每個鏡頭都要把人物外觀重寫一次**（3–6 個特徵）。只寫「同一個人」或「她」，模型會認不出來。
- 上傳多張參考圖時，在提示詞裡逐一說明：「參考圖 1：黃副總；參考圖 2：會議室場景」。最多 9 張。
- 先把單一鏡頭版本做好，再嘗試多鏡頭。

## 四、對嘴台詞

- 快速剪接的鏡頭，台詞要短（中文約 8–10 個字以內），否則嘴型會跑掉。
- 長台詞（20 字以上）要用**固定、靠近說話者**的鏡頭，而且整段只讓一個人說話。
- 兩人對話時，分成兩個鏡頭或寫清楚「A 說：⋯ B 回答：⋯」。

## 五、影片裡的文字

- AI 影片在畫面移動時很容易把字弄壞。螢幕、白板、字卡的文字**優先在後製疊上**。
- 如果關鍵畫面需要有字（例如儀表板），鏡頭必須完全固定，並在提示詞寫「螢幕上的文字必須完全靜止、不可變形或改字」；同時準備後製替換螢幕的備案。

## 六、秒數建議

| 鏡頭類型 | 秒數 |
|---|---|
| 插入鏡頭、空景、反應鏡頭 | 3–5 秒（最短只能選 5 秒就生成 5 秒再剪） |
| 有台詞的主鏡頭 | 5–8 秒 |
| 多鏡頭一次生成 | 10–12 秒 |

## 七、省點數的生成順序

1. 先用快速／草稿模式、5 秒、單一鏡頭，確認構圖。
2. 構圖滿意就**記下 seed**（如果介面有），之後用同一個 seed 微調。
3. 再用標準／正式模式生成最終版本。
4. 每段影片的提示詞、seed、秒數記在 `prompts/` 對應檔案裡，方便重做。

## 八、不要做的事

| 不要 | 原因 |
|---|---|
| 一個鏡頭塞 4 個以上同時動作 | 動作會亂掉 |
| 在影片裡放可讀文字或商標 | 字會壞、法遵風險 |
| 光線寫兩種衝突的（白天＋霓虹夜晚） | 模型只會挑一個 |
| 快速剪接配長台詞 | 嘴型對不上 |
| 叫 Seedance 生成完整配樂 | 配樂後製加，比較好控制 |
