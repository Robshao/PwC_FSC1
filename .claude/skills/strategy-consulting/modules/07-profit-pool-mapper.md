# 07 Profit Pool Mapper（利潤池地圖師）
> 階段：Analyze（分析）｜上游輸入：04 hypothesis-builder、05 customer-segmenter、06 market-sizer｜交給下游：08 competitor-war-gamer、09 strategic-options-grid、11 business-case-builder

## 這個模組要回答的問題
- 這個產業的 Value Chain（價值鏈）有哪些環節？每個環節的營收與利潤率大約是多少？
- Profit Pool（利潤池）實際落在哪些環節、被哪些角色拿走？
- 客戶應該在哪個環節參與（Where to Play，在哪裡競爭），才能拿到有吸引力的利潤，而不只是營收？

## 什麼時候用、什麼時候不用
- **要用**：市場看起來很大，但需要判斷「錢到底被誰賺走」時；或客戶考慮往上下游延伸、建立夥伴關係、選擇進入哪個環節時。因為營收最大的環節往往不是利潤最高的環節，只看 06 的市場規模會選錯戰場。
- **不用**：價值鏈單純、客戶只在單一環節且沒有延伸選項時；或利潤率資料完全無法取得、連合理代理指標都找不到時，此時應先回報資料缺口，而非硬做一張沒有根據的圖。

## 需要的輸入
- 04 的假設與通過／否決門檻（例如「某環節的利潤率顯著高於客戶目前所在環節」）。
- 06 的市場規模與計量單位；05 的區隔與付費方結構。
- 各環節代表性公司的財務資料（年報、公開說明書）、產業報告、專家訪談紀錄（需附來源與年份）。
- 任何缺少的輸入都必須向客戶或專家詢問；若無法取得，必須明確寫成「假設」，並註明負責確認的人（Owner）與期限。
- 客戶自身的成本與毛利資料屬機密，不可放入外部搜尋或未經核准的 AI 工具。

## 步驟
1. **畫出價值鏈環節**：從最上游到最終付費方，依序列出每個環節（例如產品設計、通路銷售、承保、服務提供、理賠或結算、協助服務），並標出每個環節的主要角色。
   為什麼：先有完整、不重疊的環節，營收與利潤才能被正確歸屬，不會重複計算。
2. **估算每個環節的營收**：以 06 的市場規模為總量，依金流方向拆分到各環節，確認各環節營收加總與總量邏輯一致。
   為什麼：Market Size（市場規模）衡量的是營收流量，必須先拆對營收，才能進一步計算利潤。
3. **估算每個環節的利潤率**：優先使用年報中的分部資訊；若無法取得，使用代理指標（Proxy，代理指標），例如同業上市公司的毛利率或營業利益率、專家訪談區間、成本結構推估。
   為什麼：利潤率常是未公開資料，用透明的代理方法並標示信心程度，比空白或捏造數字更可信也更可被檢驗。
4. **計算利潤池並畫圖**：各環節利潤 = 營收 × 利潤率；以橫軸為營收占比、縱軸為利潤率的方式呈現，讓面積代表利潤池大小。
   為什麼：圖像能一眼看出「營收大但利潤薄」與「營收小但利潤厚」的環節，這正是策略選擇的關鍵。
5. **分析誰拿走利潤與原因**：辨識各環節中拿走主要利潤的角色，並說明其背後的控制點（客戶關係、資料、牌照、網絡規模、議價力）。
   為什麼：利潤集中的原因決定客戶能否複製或切入，否則只是看到結果而無法行動。
6. **找出客戶可以參與的位置並對照假設**：評估客戶的能力與各環節控制點的匹配度，列出可進入、可合作、應避開的環節，並判定 04 的假設是否通過。
   為什麼：利潤池分析要回答「在哪裡競爭」，並把結論接回假設驗證；被否決的假設要退回 04。

## 品質檢查清單
- [ ] 價值鏈環節完整且不重疊，各環節營收加總與 06 的總量一致。
- [ ] 每個利潤率都有來源或明確的代理方法，並標示信心程度。
- [ ] 清楚區分市場規模（營收）與利潤池（利潤），沒有混用。
- [ ] 說明利潤被誰拿走以及背後的控制點。
- [ ] 舊資料（超過三年）與薄弱次級來源已標示。
- [ ] AI 輔助整理的財務數字已由人工對照原始年報驗證。
- [ ] 結論對照 04 假設的門檻，並給出可行動的參與建議。

## 常見錯誤
- **把市場規模當成利潤池** → 選擇營收大但利潤薄的環節，進入後無法獲利 → 每個環節都要算出利潤，並並列比較。
- **捏造或隨意假設利潤率** → 圖表看起來完整卻經不起追問 → 使用可追溯的代理指標，寫明方法並標示信心程度。
- **只看結果不看控制點** → 知道某環節利潤高，卻不知道客戶能否切入 → 補上控制點分析與能力匹配評估。
- **把多元化集團的整體利潤率套到單一環節** → 利潤率失真 → 優先使用分部資訊，否則選用業務單純的同業作為代理。

## 保險與跨境醫療服務情境提示
- 保險價值鏈常見環節包括商品設計、通路（經紀人、銀行保險）、承保與風險承擔、再保險、理賠處理與第三方管理、醫療服務提供；通路佣金與風險承擔的利潤結構差異很大。
- 跨境醫療服務中，協助服務公司、醫療機構網絡、轉診與結算平台可能各拿走不同比例的利潤；掌握醫療網絡與直接結算能力往往是控制點。
- 保險公司的利潤受投資收益與準備金影響，計算承保環節利潤時應註明是否包含投資收益，以免與其他環節比較時失準。
