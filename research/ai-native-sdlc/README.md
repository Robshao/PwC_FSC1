## 使用注意

- 「數週縮短到數小時」是手冊所述預期，不是實測數字；對外只引用自己試點量到的數字。
- 第 6 頁的數字（三分之一通話時間、每秒 50 次）是手冊示例，不是客戶資料。
- Claude Tag、Claude Design、託管 Code Review 在手冊撰寫時為預覽或測試版，對客戶說明前先確認現況。
- 客戶若同時是所內審計客戶，推案前先與 Risk & Quality 確認獨立性。
