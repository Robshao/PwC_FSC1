# 分鏡腳本｜個人年度目標影片（草稿版）

| 項目 | 設定 |
|---|---|
| 片長 | 30 秒（3 段 Dreamina 生成：8 秒 + 12 秒 + 10 秒） |
| 比例 | 16:9（方便在會議或簡報中播放） |
| 解析度 | 草稿模式先用最低解析度測試，正式模式用 720p |
| 角色 | 原創角色，不使用本人肖像（避免肖像權與一致性問題） |
| 敘事結構 | 起點 → 行動 → 願景 |
| 方法依據 | `ai-video-storyboard`（分鏡）＋ `seedance-25`（Dreamina 提示詞）；三段提示詞都已通過 `lint_prompt.py` 檢查 |

## 視覺主題（三段共用）

- **色彩**：PwC 簡報的青綠色（teal）、深藍（navy）、白、暖琥珀色燈光
- **燈光**：左側冷藍的窗外光 + 右側暖黃的檯燈；論壇場景則用明亮頂光加青綠色螢幕光
- **風格**：乾淨、半寫實、溫暖勵志
- **鏡頭運動**：每段只有一個主要運鏡（慢推、跟拍環繞、慢拉）
- **固定元素**：角色的深藍西裝外套、白襯衫，以及**青綠色識別證掛繩**（串起三段的關鍵道具）

## 步驟 0：先做角色參考圖（ref）

在 Dreamina 的**圖片生成**中使用 `prompts/ref-character.txt`，挑一張最滿意的三視圖，存成 `@Image 1`，之後三段影片都要上傳它。

> 角色預設是 20 多歲的東亞商務人士，可以依自己的形象改寫性別、髮型、服裝。

## 分鏡表

### 鏡頭 1（0–8 秒）｜起點：決定走出去
- **畫面**：傍晚的辦公室，角色停下打字、拿起空白的青綠色識別證，站起來戴上。
- **運鏡**：側面中景慢慢推進到中近景。
- **提示詞**：`prompts/clip1.txt`

### 鏡頭 2（8–20 秒）｜行動：論壇現場認識前輩
- **畫面**：明亮的金融科技論壇展場，角色穿過人群，走向一位銀髮資深人士，握手交談，接著拿出手機互掃（LinkedIn 連結的動作，畫面不出現 App 標誌）。
- **運鏡**：從背後跟拍，平順環繞到側面雙人中景。
- **提示詞**：`prompts/clip2.txt`

### 鏡頭 3（20–30 秒）｜願景：收藏第九條掛繩
- **畫面**：夜晚回到辦公室，牆上掛滿不同顏色的論壇掛繩和握手合照；角色把青綠色掛繩掛上最後一個掛鉤，退後一步，露出驕傲的微笑。
- **運鏡**：從手部特寫慢慢拉遠到中遠景，帶出整面牆。
- **提示詞**：`prompts/clip3.txt`

## CapCut 後製字幕（中文字一律在後製加）

| 時間 | 字幕 |
|---|---|
| 0–4 秒 | 2026，我想走出辦公室 |
| 4–8 秒 | 年度目標：參加 5–10 場金融科技商業論壇 |
| 8–13 秒 | 每一場，主動認識一位資深前輩 |
| 13–20 秒 | 當面交換 LinkedIn，分享 PwC FSC1 正在做的事 |
| 20–26 秒 | 10 位前輩・10 段連結 |
| 26–30 秒 | 讓更多人看見 FSC1 |

## 後製檢查清單

- [ ] 草稿模式先生成三段，確認角色一致、動作正確（步驟 5）
- [ ] 找需求方（主管）看草稿，記錄要修改的地方（步驟 6）
- [ ] 正式模式重新生成需要修改的段落（步驟 7）
- [ ] 在 CapCut 依序接上三段，段落之間用 0.3 秒交叉淡化
- [ ] 統一調色：稍微加強青綠與琥珀色調，讓三段色調一致
- [ ] 加背景音樂：溫暖、輕快的鋼琴或電子樂，約 100 BPM，音量壓在環境音之下
- [ ] 加上表格中的中文字幕，字體統一（例如思源黑體），白字加淡陰影
- [ ] PwC 的名稱或標誌是否能出現、怎麼出現，先依所內 AI 影片規範確認（步驟 1）；可以使用的話也只在後製加，不讓 AI 生成
- [ ] 匯出 1920×1080、30fps 的 MP4

## 為什麼這樣設計

1. **一條掛繩串起整個故事**：鏡頭 1 戴上、鏡頭 2 在現場使用、鏡頭 3 掛上收藏牆。不用文字，觀眾也看得懂「累積」的意思。
2. **畫面裡不放文字**：Dreamina 生成的中文字常常變形，所以數字（5–10 場、10 位）都交給字幕，確保內容精準。
3. **每段只做一件事、只用一個運鏡**：降低生成失敗的機率，節省點數與時間。
4. **原創角色加參考圖**：三段使用同一張角色圖，臉和服裝才不會每段都不一樣。
