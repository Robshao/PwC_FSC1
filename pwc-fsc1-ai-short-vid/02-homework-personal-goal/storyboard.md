# 分鏡腳本｜個人年度目標影片（草稿版，15 秒）

| 項目 | 設定 |
|---|---|
| 片長 | 15 秒（3 段 Dreamina 生成，每段 5 秒） |
| 比例 | 16:9（方便在會議或簡報中播放） |
| 解析度 | 草稿模式先用最低解析度測試，正式模式用 720p |
| 角色 | AI 原創角色：約 30 歲的東亞男性商務人士（不使用本人肖像） |
| 敘事結構 | 起點 → 行動 → 願景 |
| 方法依據 | `ai-video-storyboard`（15 秒 = 3 鏡頭）＋ `seedance-25`（Dreamina 提示詞）；三段提示詞都已通過 `lint_prompt.py` 檢查 |

## 視覺主題（三段共用）

- **色彩**：青綠色（teal）、深藍（navy）、白、暖琥珀色燈光
- **燈光**：左側冷藍窗光 + 右側暖黃檯燈；論壇場景用明亮頂光加青綠色螢幕光
- **風格**：寫實、溫暖勵志
- **鏡頭運動**：每段只有一個主要運鏡
- **固定元素**：深藍西裝外套、白襯衫（領口打開、不打領帶），以及**青綠色識別證掛繩**

## 步驟 0：生成原創角色設定圖

不使用本人肖像，改用 AI 生成的原創商務人士角色：

1. 在 Dreamina **圖片生成**貼上 `prompts/character-sheet.zh.txt`（或英文版 `character-sheet.txt`），產生同一位男性的三視圖（正面、四分之三側、側面）。
2. 生成 3–4 張，挑一張三個角度的臉最一致、服裝最乾淨的，存成 `character.png`。
3. 之後每次生成鏡頭圖片或影片，都上傳這張設定圖當參考，三段的人物才會是同一個人。

> 角色外觀：約 30 歲的東亞男性，短而俐落的黑髮、自然側分，沒有鬍子，深藍西裝外套、白襯衫領口敞開不打領帶、深藍西褲、黑皮鞋。
>
> 生成素材不要提交到 Git 儲存庫（已設定 `.gitignore`）。

## 後製檢查清單

- [ ] 草稿模式生成三段，確認三段是同一個人、動作正確（步驟 5）
- [ ] 找主管看草稿，記錄要修改的地方（步驟 6）
- [ ] 正式模式重新生成需要修改的段落（步驟 7）
- [ ] 在 CapCut 依序接上三段，段落之間用 0.3 秒交叉淡化
- [ ] 統一調色，讓三段的青綠與琥珀色調一致
- [ ] 加背景音樂：溫暖、輕快，約 100 BPM，15 秒內收尾
- [ ] 加上中文字幕，字體統一（例如思源黑體），白字加淡陰影
- [ ] PwC 的名稱或標誌依所內規範確認後，只在後製加
- [ ] 匯出 1920×1080、30fps 的 MP4

## 為什麼這樣設計

1. **15 秒 = 3 個 5 秒鏡頭**：這是短影片最常見的節奏，每段只做一件事，生成成功率最高。
2. **一條掛繩串起故事**：戴上 → 使用 → 收藏，不用文字也看得懂「累積」。
3. **畫面裡不放文字**：數字和中文都交給字幕，避免 AI 生成的中文字變形。
4. **原創角色設定圖**：不使用本人肖像，避免肖像權疑慮；三段都參考同一張設定圖，人物保持一致。
