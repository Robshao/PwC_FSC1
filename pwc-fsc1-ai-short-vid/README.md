# PwC FSC1 AI 短影片專案

FSC = Financial Services Consulting（金融服務諮詢）。

## 專案目標

讓影片成為新的表達方式：口說 → 簡報 → AI 影片，讓想法與價值更容易被理解。

- **老闆期望**：快、看得到進度——每週有小進度、小成果，透過持續產出累積影片製作經驗。
- **PM 期望**：控制投入、降低壓力——我們不是影視專業人員，每天投入約 3 小時，循序練習。
- **共同方向**：以可持續的投入，穩定交付看得見的成果。

## 時程

| 階段 | 截止 | 主題 | 交付成果 |
|---|---|---|---|
| 01 個人練習（回家功課） | 10/8（週四） | 個人年度目標 | 草稿影片 |
| 02 主題實作 | 10/12（週一）下班前 | 老闆指定內容 | 草稿影片 |

先完成草稿並取得回饋，再推進正式影片與後製。
