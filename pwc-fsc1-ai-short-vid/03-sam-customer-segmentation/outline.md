# 故事大綱｜客戶分層影片（Sam 指定主題，10/12 交付草稿）

## 背景與目的

- **商業目的**：未來向保險業客戶推「客戶分層」相關服務，例如分層策略建立、系統導入。
- **影片目的**：讓保險業客戶**認同客戶分層的重要性**。
- **觀眾（假設）**：保險公司的高階主管、業務通路與行銷主管。
- **參考素材**：PwC「戰略層面客戶分層框架」（購買能力 × 生命階段）、「滿期退保數據分析工具」（工具 A–D：客戶分層、家庭保障缺口、客戶緊密度、轉保預測），以及「保險客戶人物誌 02｜40 歲家庭責任承擔者」。

## 大綱五要素

| 要素 | 內容 |
|---|---|
| 短片定位 | 15 秒，對話情境式短片（沒有旁白），用於客戶提案或研討會開場 |
| 核心主題 | 同一位客戶，用錯方式服務會失去信任；**先分層、看懂需求**，推薦才會對準 |
| 人物設定 | 主角：**志明**，40 歲，科技業專案主管，已婚育有一子（8 歲）。配角：錯誤示範的業務員（強勢推銷）、正確示範的顧問（溫和、拿平板分析）、志明的太太 |
| 故事主線 | 錯誤服務（只看收入推高額保單）→ 正確服務（先算家庭保障缺口）→ 客戶安心、信任建立。一句話：**看懂客戶是誰，才知道他真正缺什麼。** |
| 整體風格 | 寫實電影感；錯誤示範用冷色調、正確示範用暖色調，呼應人物誌的紅綠對比 |

## 對應 PwC 客戶分層框架

| 影片裡的情節 | 對應的分層概念 |
|---|---|
| 志明 40 歲、有房貸、有小孩 | 生命階段 40–49 歲、「關注家庭／成熟家庭」客群 |
| 業務員只看「收入高」就推高保費 | 只用單一維度（購買能力）判斷，忽略生命階段與既有保障 |
| 顧問先算「收入中斷後的缺口」 | 工具 B：家庭保障缺口 = 個人保障缺口 + 關係人保障缺口 |
| 志明夫妻安心、信任建立 | 提升客戶緊密度（工具 C），降低退保風險 |
