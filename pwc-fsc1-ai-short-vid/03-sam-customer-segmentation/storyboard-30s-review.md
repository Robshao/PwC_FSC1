# 30 秒分鏡審查｜連貫性、理解速度、帶入感

審查日期：2026-10-12
使用的技能：`video`（AI 影片製作原則）、`ad-creative` 的 Hook System 與 Awareness 框架、`marketing-psychology`（對比效應、峰終定律、損失規避）

## 總評

| 面向 | 評分 | 一句話 |
|---|---|---|
| 帶入感（對志明） | ⭐⭐⭐⭐☆ | 台詞取自人物誌、台灣生活細節到位，觀眾會覺得「這就是我身邊的人」 |
| 前 3 秒抓住注意力 | ⭐⭐⭐☆☆ | 台詞很強，但畫面只是「一個人看手機」，靜音時看不出發生什麼事 |
| 鏡頭之間的連貫性 | ⭐⭐⭐☆☆ | 鏡頭 1→2 很順；2→3、3→4 有跳接，觀眾要自己猜 |
| 「客戶分層」被看見 | ⭐⭐☆☆☆ | **最大缺口**：整支片沒有一個畫面明確說出「分層」，平板上只有模糊色塊 |
| 帶入感（對真正的觀眾：保險公司主管） | ⭐⭐☆☆☆ | 主管會同情志明，但不一定會想到「我們公司也是這樣」 |

**結論：故事骨架是對的，不需要重拍。** 主要問題都可以用**後製字卡與轉場**補起來，不必重新生成 Seedance 影片。

## 逐項診斷

### 1. 前 3 秒（Hook）：台詞強，但畫面與字幕沒有分工

`ad-creative` 的 Hook System 認為，影片開頭由三個部分組成，而且三者要互補、不重複：

| 組成 | 目前 | 問題 |
|---|---|---|
| 畫面動作 | 志明在捷運上看手機 | 很常見，靜音滑過時看不出事件；手機畫面是模糊的，觀眾不知道他看到了什麼 |
| 台詞 | 「我要是倒下，家裡撐得住嗎？」 | ✅ 很好：取自人物誌原句，會讓觀眾想知道答案 |
| 開場字幕 | **沒有** | 少了一格；靜音觀看的人（例如會議室投影、手機滑到）完全不知道他是誰 |

**建議：** 0–3 秒加上人物名牌字卡「志明｜40 歲｜科技業主管｜房貸 800 萬｜孩子 8 歲」，數字全部取自人物誌。手機畫面再疊一個後製的訊息泡泡「同事住院了⋯」，讓觀眾立刻知道觸發他擔心的事件是什麼。

### 2. 鏡頭 2→3 的跳接：為什麼突然在咖啡店？

觀眾看到夫妻煩惱保單，下一秒志明就在咖啡店被推銷，中間少了一句交代。

**建議：** 鏡頭 3 開頭加一個小時間字卡「隔天，找業務員諮詢」。

### 3. 鏡頭 3→4 的跳接：最關鍵的結構問題

目前觀眾很可能把故事理解成：「志明拒絕了業務員 → 後來找到另一位比較好的顧問」。這樣理解也說得通，但影片要傳達的「**同一位客戶、兩種服務**」，直到最後 3 秒的結尾字卡才揭曉。

`marketing-psychology` 的**對比效應**指出：先把「之前」的狀態清楚呈現，「之後」的改變才會鮮明。對比必須讓觀眾當下就意識到，而不是事後才恍然大悟。

**建議：** 在 15 秒處（A、B 兩段接點）加入「**倒帶**」轉場：畫面快速倒轉約 0.5 秒，接著打出全螢幕字卡「**同一位志明，換一種服務方式⋯**」。這樣觀眾一進入 B 段就知道，這是同一個情境的另一種可能。

### 4. 「客戶分層」沒有被看見：影片最大的缺口

這支影片的目的是讓保險業客戶認同客戶分層的重要性。但目前畫面上能代表「分層」的，只有鏡頭 5 平板上的模糊色塊。觀眾看得出顧問很專業，卻看不出她「為什麼」能一開口就說對話。

**建議：** 在鏡頭 4 或鏡頭 5 的平板上，用後製疊加一張清楚的「客戶分層卡」。這是 `video` 技能建議的做法：AI 生成不了可讀的文字，就用後製疊加。

```
客群｜關注家庭・40–49 歲
特徵｜高房貸・保障以團保為主
缺口｜收入中斷後的家庭保障 ⚠
```

可以再搭配 PwC 戰略分層框架的縮圖，把志明所在的格子亮起來（如果所內規範允許使用這張圖）。這一格畫面，就是影片和 PwC「客戶分層」服務之間的橋樑。

### 5. 對真正觀眾的帶入感：讓主管看見自己的風險

觀眾會同情志明，但保險公司主管看完不一定會聯想到自己的公司。`marketing-psychology` 的**損失規避**指出：人對「失去」的感受比「得到」更強烈。

**建議：**
- **鏡頭 3 結尾**加一行後果字卡：「推錯的保單 → 信任流失 → 退保風險」。這呼應 PwC 滿期退保分析，而且不寫任何沒有根據的數字。
- **結尾字卡**改成直接對主管提問，讓他們把自己帶入情境：

```
同一位客戶，兩種服務
你的客戶，被看懂了嗎？
客戶分層｜策略建立・系統導入
```

### 6. 結尾：峰終定律運用得很好

`marketing-psychology` 的**峰終定律**指出：人對一段經驗的記憶，取決於最強烈的時刻和結尾。鏡頭 6 兒子抱住爸爸的大肚子是全片情緒最高點，又剛好在結尾，設計很好，**保留不動**。

### 7. 製作風險：兩段影片的志明可能不一樣

A、B 兩段是分開生成的，志明的臉或聲音只要有落差，觀眾就會出戲，帶入感也會下降。應對方式已經寫在提示詞說明裡：B 段多上傳 `character.png`，聲音差太多就換成真人錄音。
