# 劇本與分鏡｜客戶分層影片 v5（補上「為什麼去找業務員」的橋段，約 44.7 秒）

## 問題：0:16–0:18 卡住

| 原因 | 說明 |
|---|---|
| 畫面真的停住了 | v4 為了不切掉雅婷的尾音，餐桌鏡頭最後 0.4 秒是停格 |
| 場景硬切 | 夜晚、安靜、哭泣的家 → 白天、明亮、吵雜的咖啡店，中間沒有任何過渡 |
| 動機斷掉（最主要） | 太太問「保單夠嗎？」，下一秒業務員就在推銷。觀眾不知道是誰找誰、為什麼見面 |
| 兩種服務的起點不對稱 | 錯誤示範直接從推銷開始，觀眾沒有看到志明原本「想問什麼」，所以業務員「答非所問」的荒謬感出不來 |

## 解法

1. **草稿 5（只改剪輯，已完成）**：拿掉停格；餐桌鏡頭淡出到黑底章節字卡「一週後／志明主動找保險業務員，想問理賠」（1.2 秒）；咖啡店環境音提早進來（J-cut）。
2. **v5（建議補一個新鏡頭）**：鏡頭 3.5「清晨陽台打電話」。志明問的是「我的保單能理賠多少？」，業務員卻回答「趕快加保」。觀眾先聽到需求，再看到答非所問，咖啡店的推銷就有了起因。
3. **選用**：鏡頭 4a「林顧問來訪」，讓正確示範也有對稱的開場。會讓片長變成約 48 秒，超過 45 秒上限，需要取捨。
