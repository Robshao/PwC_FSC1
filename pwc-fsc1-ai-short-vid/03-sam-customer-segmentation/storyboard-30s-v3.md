# 劇本與分鏡｜客戶分層影片 v3（醫院確診版・30 秒）

> v3（2026-10-12）：依使用者建議，把觸發事件改成「志明在醫院拿到癌症診斷」。A 段是同一天的「衝擊」，B 段是「兩種服務」的對比。v2 的審查原則（人物名牌、倒帶轉場、分層卡、結尾提問）全部保留。

## 為什麼 v2 草稿看起來不順

| 問題 | 原因 |
|---|---|
| 三個場景互不相干 | 早上捷運 → 晚上餐桌 → 下午咖啡店，時間順序倒退，也沒有東西把三個場景串起來 |
| 觸發事件太弱 | 「看手機上的訊息」是靠後製泡泡解釋的，畫面本身看不出發生了什麼事 |
| 錯誤與正確分在兩段 | A 段結尾是錯誤示範、B 段開頭是盤點，觀眾要在接點才發現兩段的關係 |

## v3 的修正

1. **同一天、時間往前走**：下午醫院 → 傍晚捷運 → 晚上回家，光線從陰天、夕陽到夜晚逐漸變暗。
2. **一個道具串起 A 段**：白色檢查報告信封從醫院拿在手上，捷運上捏在手裡，回家放在餐桌上。
3. **觸發事件本身就看得懂**：拿著報告愣在醫院門口，不需要後製解釋。
4. **對比集中在 B 段**：鏡頭 4 錯誤服務 → 倒帶字卡 → 鏡頭 5、6 正確服務，觀眾在同一段裡直接看到對比。
5. **合理性修正**：剛確診的人通常很難再通過新保單的核保。所以業務員「推銷新保單」顯得更荒謬，也讓錯誤示範更有說服力；顧問則先處理「既有保單能理賠多少」，再談家庭缺口，符合人物誌「理賠支援」與「除外、等待期與核保結果」的顧慮。
